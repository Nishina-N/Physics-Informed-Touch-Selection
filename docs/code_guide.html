MuJoCo Menagerie の G1（Dex3 ハンド付き）に、机・頭部カメラ・部品を足してシーンを組み立てる関数のうち、部品を作る部分です。part=(fl, L) を渡すと、手前に高さ 4mm・長さ fl のフランジ、奥に幅と高さ 20mm・長さ L の本体をつないだ部品になります。

入力と出力
  • 入力：部品の幅 s（20mm）、part=(フランジの長さ, 本体の長さ)
  • 出力：mujoco.MjSpec（まだコンパイル前のモデル）。部品の名前は cube_20mm、フランジは cube_20mm_flange
読みどころ
  1. フランジと本体は同じ body に付けた2つの箱です。1つの剛体なので、フランジだけ挟んでも本体ごと動きます。
  2. フランジの箱は part[0] + 0.001 と 1mm 長くして本体に重ね、隙間ができないようにしています。
  3. condim=4 はねじり摩擦を入れる設定です。既定の 3 だと、挟んだ軸のまわりに部品が回ってしまいます。
  4. 摩擦 0.5 はここでの初期値です。学習データと実験では、試行ごとに 0.3〜1.0 の値に置き換えます（次の節）。

関数の前半（この抜粋より上）では、骨盤を世界に固定し、頭部カメラ D435i を胴体に付け、楕円の摩擦錐と impratio=10 で把持の滑りを抑える設定をしています。

  3. CAM_P は開始姿勢のシミュレーションで測ったカメラの位置です。

def randomize(s, rng):
    m = s.m
    mu = rng.uniform(*MU_R)
    hand = [i for i in range(m.ngeom) if m.body(m.geom_bodyid[i]).name.startswith("right_hand")]
    for gid in hand + [m.geom(s.cube).id, m.geom(s.cube + "_flange").id]:
        m.geom_friction[gid, 0] = mu              # 接触の摩擦は2つの形状の大きい方なので、指と部品の両方に入れる
    ms = rng.uniform(*MASS_R)
    b = m.body(s.cube).id
    m.body_mass[b] *= ms; m.body_inertia[b] *= ms
    gs = rng.uniform(*GAIN_R)
    for i in range(m.nu):
        if m.actuator(i).name.startswith("right_hand"):
            m.actuator_gainprm[i, 0] *= gs; m.actuator_biasprm[i, 1] *= gs
    mujoco.mj_setConst(m, mujoco.MjData(m)); mujoco.mj_forward(m, s.d)   # 質量を変えたら定数を計算し直す（しないと不安定になり、成功率が見かけ上下がった）。s.d を作業領域に使うと状態が壊れる
    return dict(mu=mu, mass_scale=ms, gain_scale=gs)

1回の把持ごとに、摩擦・部品の質量・指の制御ゲインを乱数で変えます。これらは特徴量には入れないので、予測器は「これらがばらついたときの平均的な成功確率」を学びます。

入力と出力
  • 入力：シミュレーション s、乱数 rng
  • 出力：引いた値 dict(mu, mass_scale, gain_scale)（記録用）
読みどころ
  1. 摩擦 μ は 0.3〜1.0。MuJoCo は接触する2つの形状の摩擦の大きい方を使うので、指と部品の両方に同じ値を入れます。
  2. 質量は 0.7〜1.3 倍。慣性も同じ倍率で変えます。
  3. 指のゲインは 0.8〜1.2 倍。位置制御なので gainprm と biasprm を同じ倍率で変え、目標角の位置は変えずに硬さだけを変えます。
  4. mj_setConst で定数を計算し直します。これを忘れると動きが不安定になり、成功率が見かけ上下がりました（コメントに残してあります）。

上の定数は、形の範囲（フランジ 10〜30mm、本体 12〜20mm）、見え方の4段階、物理の値の範囲です。推論側の run_branch.py も同じ範囲を使います。

def sample(i):
    rng = np.random.default_rng(20000 + i)
    fl, L = rng.uniform(*FL_R), rng.uniform(*L_R)
    vis = VIS_LEVELS[rng.integers(4)]
    yaw, dy = rng.uniform(-20, 20), rng.uniform(-0.01, 0.01)
    t0 = time.time()
    s = S.ShelfSim(W, visible=vis, part=(fl, L), dxy=(0, dy), yaw_deg=yaw)
    phys = randomize(s, rng)
    d = s.d
    R = d.body(s.cube).xmat.reshape(3, 3); yw = np.arctan2(R[1, 0], R[0, 0])
    front = d.body(s.cube).xpos + R @ np.array([-(fl + L / 2), 0, 0])
    a = rng.uniform(fl - 0.006, fl + L + 0.004)          # 部品の軸に沿った挟む点（手前の面から）
    b = rng.uniform(-0.008, 0.008)                        # 横のずれ
    gx = front[0] + np.cos(yw) * a - np.sin(yw) * b
    gy = front[1] + np.sin(yw) * a + np.cos(yw) * b
    gz = bs.TABLE_TOP_Z + W / 2 + rng.normal(0, 0.001)
    g = s.grasp([gx, gy, gz])
    rec = dict(i=i, fl=fl, L=L, vis=vis, yaw=float(np.degrees(yw)), dy=dy, a=a, b=b, dz=gz - bs.TABLE_TOP_Z - W / 2,
               u=a - fl, v=fl + L - a, reach=gx - s.front_x, success=g["success"], closed=g["closed"],
               board=g["board"], sec=time.time() - t0, **phys)
    del s; gc.collect()
    return rec

1つの学習データを作ります。形・見え方・向きを乱数で決めて部品を置き、真の形に対して挟む点を少しずつ振って掴み、成功したかを記録します。これを 8,000 回繰り返します。

入力と出力
  • 入力：データの番号 i（乱数の種は 20000 + i）
  • 出力：1行の記録。特徴 u, v, b, yaw, L, reach と結果 success（ほかに確認用の値）
読みどころ
  1. 挟む点は、部品の軸に沿って手前の面から a ∈ [fl − 6mm, fl + L + 4mm]、横に b ∈ ±8mm で引きます。本体の外（フランジの上や奥の何もない所）も含めるので、失敗の例も十分に集まります。
  2. 特徴の u = a − fl は本体の手前の縁から挟む点まで、v = fl + L − a は挟む点から本体の奥の縁までの距離です。
  3. reach は天板の前端から挟む点までの奥行きです。奥ほど手首が天板に近づくので、成否に関わります。
  4. 掴む動作は s.grasp()（後の節）です。ここでは触らずに、天板の手前から差し込んで掴みます。

挟む点 target_xyz に親指と中指の間を合わせて掴み、天板の外へ引き出して持ち上げます。学習データでも、推論の評価でも、この同じ関数で成否を決めます。

入力と出力
  • 入力：挟む点（世界座標）
  • 出力：success（4cm 以上持ち上がり、2秒保持できたか）、持ち上がった高さ、天板に当たった部位など
読みどころ
  1. 手の経路は学習していません。決めた経由点を逆運動学（mink）で解き、関節の目標を直線で補間する決めうちの動作です（move_linear）。
  2. 触った後で手が天板の下にあるとき（DIRECT）は、腕を天板の外へ戻さず、今の高さ以上を保って挟む点の真上へ移ります。そうでなければ天板の手前から水平に差し込みます。

  4. 成功の判定は rise > 0.04：2秒保持した後に、最初の位置より 4cm 以上高いことです。

def close_each(sim, seconds=1.0, squeeze=None):
    """各指を開→閉へ進め、物体に触れた指はそこで止める。両方触れたら、両方を squeeze だけ同時に進める。"""
    m, d = sim.m, sim.d
    cid = m.body(sim.cube).id
    tips = {"thumb": m.body("right_hand_thumb_2_link").id, "middle": m.body("right_hand_middle_1_link").id}
    s0 = g.PER_SIZE[sim.cube]["s0"]
    sq = g.PER_SIZE[sim.cube]["squeeze"] if squeeze is None else squeeze
    n = int(seconds / m.opt.timestep); ds = (g.S_END - s0) / n
    s = {"thumb": s0, "middle": s0}; stop = {}
    for _ in range(n):
        touch = set()
        for c in d.contact[:d.ncon]:
            b1, b2 = m.geom_bodyid[c.geom1], m.geom_bodyid[c.geom2]
            if cid in (b1, b2):
                touch.add(b2 if b1 == cid else b1)
        for f in s:
            if f not in stop and tips[f] in touch:
                stop[f] = s[f]
            if f not in stop:
                s[f] = min(g.S_END, s[f] + ds)
        if len(stop) == 2:
            break
        sim.set_hand(hand_q2(s["thumb"], s["middle"])); sim.mj_step()
    if len(stop) < 2:
        return None
    k = max(1, int(0.3 / m.opt.timestep))                  # 0.3秒かけて両方を同時に締める
    for i in range(k):
        a = sq * (i + 1) / k
        sim.set_hand(hand_q2(stop["thumb"] + a, stop["middle"] + a)); sim.mj_step()
    return stop

親指と中指を、それぞれ開いた状態から閉じる方向へ進めます。部品に触れた指はそこで止め、もう一方だけを進めます。両方が触れたら、0.3秒かけて両方を同じだけ締めます。

入力と出力
  • 入力：シミュレーション、閉じる時間
  • 出力：各指が止まった位置。片方しか触れなければ None
読みどころ
  1. 同時に閉じると、先に当たった指が部品を押して動かします。指ごとに止めることで、挟む点がずれにくくなります。
  2. 接触の判定は d.contact の中から、部品と指先のリンクの組を探しています。

def reliability(p, y, bins=(0, .1, .3, .5, .7, .9, 1.01)):
    rows = []
    for lo, hi in zip(bins[:-1], bins[1:]):
        k = (p >= lo) & (p < hi)
        if k.sum():
            rows.append((lo, hi, int(k.sum()), float(p[k].mean()), float(y[k].mean())))
    return rows

def yaw_from_depth(cam, dep, mask, ztab, w=0.020):
    """フランジの手前の縁を深度で直線に当てはめて部品の向きを出す。
    領域の形だけでは向きがほとんど決まらなかった（推定が事前分布の中央0°に寄り、真の向きとの相関が−0.92）。
    手前の縁の向き（dx/dy = −tan yaw）から yaw を得る。点が足りなければ None。"""
    Pw = cam.to_world(dep)[mask]
    Pw = Pw[(Pw[:, 2] > ztab + 0.0015) & (Pw[:, 2] < ztab + 0.007)]   # フランジの上面と手前の面（本体の点を混ぜない）
    if len(Pw) < 20:
        return None
    y0 = np.median(Pw[:, 1]); edges = np.arange(y0 - 0.007, y0 + 0.007 + 1e-9, 0.002)   # 左右の端は領域の誤りが多いので中央14mm
    ys, xs = [], []
    for a, b in zip(edges[:-1], edges[1:]):
        q = Pw[(Pw[:, 1] >= a) & (Pw[:, 1] < b)]
        if len(q) >= 3:
            ys.append((a + b) / 2); xs.append(np.percentile(q[:, 0], 5))
    if len(ys) < 3:
        return None
    t = np.polyfit(ys, xs, 1)[0]
    return float(-np.arctan(t))

                            rng.uniform(*L_range, N_PRIOR)])

def choose_touch_m(parts, grasp_cands, touch_cands):
    """触った後の最良の成功確率の期待値が最大になる触る点（1手先読み、予測器の行列を使い回す）。"""
    Pm = prob_matrix(parts, grasp_cands)
    best = (-1.0, None)
    for x, y in touch_cands:
        ev = 0.0
        for o in (MISS, CENTER, OTHER, FLANGE):
            lk = touch_lik(parts, x, y, o); s = lk.sum()
            if s / len(parts) < 1e-6:
                continue
            ev += (s / len(parts)) * float(((lk / s) @ Pm).max())
        if ev > best[0]:
            best = (ev, (x, y))
    return best[1], best[0]

触る点の候補ごとに、「そこを触ったら何が観測されそうか」と「観測ごとに更新した後、最良の掴む点の成功確率はいくつか」を計算し、その期待値が最大の点を選びます。この研究の中心の式です。

  2. lk は観測 o が得られる確率を粒子ごとに並べたもので、その平均 s / len(parts) が P(o | u, b) です。

B_PAD_FRONT, B_TIP_FRONT, B_TIP_BACK, B_PAD_BACK = -0.011, -0.003, 0.002, 0.012
BLUR = 0.001            # 境界のぼかし[m]（位置の誤差と指の形のばらつき）
EPS = 0.02              # どの観測にも残す確率（まれな外れ値で粒子が全滅しないように）

def _sig(z):
    return 1.0 / (1.0 + np.exp(-z / BLUR))


def axial(parts, x, y):
    """点 (x,y) の、各粒子の部品軸に沿った座標 a と横のずれ b。"""
    dx, dy = x - parts[:, 0], y - parts[:, 1]
    c, s = np.cos(parts[:, 2]), np.sin(parts[:, 2])
    return c * dx + s * dy, -s * dx + c * dy


def touch_lik(parts, x, y, obs):
    """観測 obs が得られる確率を粒子ごとに返す。"""
    a, b = axial(parts, x, y)
    u = a - parts[:, 3]; v = a - parts[:, 3] - parts[:, 4]
    inside = _sig(W / 2 + LAT_TOUCH - np.abs(b))              # 横に外れていれば何にも当たらない
    body_pad_f = _sig(u - B_PAD_FRONT) * (1 - _sig(u - B_TIP_FRONT))
    body_tip = _sig(u - B_TIP_FRONT) * (1 - _sig(v - B_TIP_BACK))
    body_pad_b = _sig(v - B_TIP_BACK) * (1 - _sig(v - B_PAD_BACK))
    rest = 1 - body_pad_f - body_tip - body_pad_b
    on_fl = _sig(a) * (1 - _sig(u - B_PAD_FRONT))              # フランジの上（本体の角に指が届く手前まで）
    p = {CENTER: body_tip * inside, OTHER: (body_pad_f + body_pad_b) * inside, FLANGE: np.minimum(on_fl, rest) * inside}
    p[MISS] = np.clip(1 - p[CENTER] - p[OTHER] - p[FLANGE], 0, 1)
    return EPS / 4 + (1 - EPS) * p[obs]

def ask_smolvlm(image, instruct, model_name):
    """SmolVLM に画像と指示文を渡し、答え（文字列）を返す。"""
    import torch
    from transformers import AutoProcessor

        from transformers import AutoModelForImageTextToText as AutoVLM
    except ImportError:                                       # 古い transformers
        from transformers import AutoModelForVision2Seq as AutoVLM
    dev = "cuda" if torch.cuda.is_available() else "cpu"
    dtype = torch.bfloat16 if dev == "cuda" else torch.float32
    proc = AutoProcessor.from_pretrained(model_name)
    import transformers
    from packaging.version import Version
    kw = {"dtype": dtype} if Version(transformers.__version__) >= Version("4.56") else {"torch_dtype": dtype}
    model = AutoVLM.from_pretrained(model_name, **kw).to(dev).eval()
    q = QUESTION.format(instruct=instruct)

    inputs = proc(text=prompt, images=[image], return_tensors="pt").to(dev)

    ans = proc.batch_decode(out[:, inputs["input_ids"].shape[1]:], skip_special_tokens=True)[0].strip()
    return q, ans, dev
