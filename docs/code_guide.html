    かかる時間の目安

    処理回数目安
    集計（analyze_*.py）—数秒
    予測器の学習8,000件数秒
    把持1回（gen_grasp_data）1約1.6秒
    実験2の1配置（0〜4回触る）1約13秒
    学習データを作り直す8,0001並列で約3.5時間
    実験2を作り直す120配置1並列で約26分

    把持1回と実験2の1配置は、この作業環境（クラウドの Linux）で測った中央値です。PC の性能で変わります。並列数 n を増やすと、その分だけ短くなります。

    つまずきやすい所

    • ParseXML: Error opening file：menagerie が third_party/mujoco_menagerie にない。手順3をやり直す。スクリプトはリポジトリの直下で実行する。
    • 実験のスクリプトを実行しても何も起きない：results/ に結果が入っていて、済んだ配置を飛ばしている。やり直すときは手順6のとおり結果を退避する。
    • 予測器を読み込むと警告が出る：scikit-learn の版が 1.8.0 でない。uv sync で入れた環境（uv run）で実行する。
